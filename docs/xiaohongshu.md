## 正文

之前吃过一次亏。

那家公司财报看着很漂亮：营收连年增长、净利润也在涨、PE 也不高。买进去不到半年，公告「前期会计差错更正」——几个亿的利润直接没了。

后来我才知道，很多问题早就写在财报里了，只是没人会一行行去看。

于是我干脆写了个小程序，把 A 股 5000 多家公司的财报全部拉下来跑一遍，让机器帮我盯。

🔍 **它会看什么**

▫️ 净资产是不是负的
▫️ 是不是连续两年在亏
▫️ 经营活动现金流是不是连续为负
▫️ 商誉占净资产是不是太高

这几条不是我拍脑袋想的。

我拿全市场 313 家 ST 公司（就是被交易所贴上风险警示的那些）当测试样本，看这些规则能不能把它们挑出来。

结果挺有意思：

"净资产为负"这条，在 ST 公司里的触发率是普通公司的 **37 倍**。

但另一条我原本最有信心的——"经营现金流长期低于净利润"——实测下来只有 **0.16 倍**，也就是 ST 公司反而不太容易触发它。

原因很反直觉：亏损公司这条直接被跳过了，所以它实际筛出来的是「成长期公司」，不是「有问题的公司」。

这条被我删了。宁可少一条规则，也不想给正常公司乱贴标签。

📊 **跑一遍的结果**

5000 多家公司，48 秒跑完。

标红的（高危）112 家，基本都是 ST。标黄的（需要留意）大概 1200 家。

每一条都会告诉你：哪条规则触发了、具体数字是多少、依据是哪一期财报。不是给个分数让你猜。

💡 **我想说的是**

这不是一个"告诉你买什么"的工具，恰恰相反——它是帮你**排除掉不该看**的。

散户最容易犯的错，是在一家本来就有问题的公司上花几周时间研究。先把雷排掉，剩下的时间才值得花在真正的好公司上。

代码我开源了，免费，不用注册也不用填 API Key。

搜 github 用户名 WilShi，仓库叫 cnstock。
